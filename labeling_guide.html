2กฎการตีกรอบ (Bounding Box)

ถูกกรอบชิดขอบเมล็ดทั้งเมล็ด
ผิดตีกรอบเฉพาะจุดตำหนิ → ต้องคลุมทั้งเมล็ด
ผิดรวมเมล็ดที่ชิดกันไว้ในกรอบเดียว → 1 เมล็ด = 1 กรอบ
ถูกเมล็ดชิดกัน แยกกรอบละเมล็ด (กรอบซ้อนกันได้)
ถูกเมล็ดที่ขอบภาพ: ติดป้ายเมื่อเห็นเกิน 50%
ถูกสิ่งแปลกปลอม: ตีกรอบคลุมวัตถุทั้งชิ้น
ถูกเปลือกที่หลุดแยกเป็นชิ้น → foreign_matter
ถูกเปลือกยังติดเมล็ด → dried_cherry

3เมล็ดเดียวมีหลายตำหนิ → ใส่ป้ายเดียว ตามลำดับความรุนแรง

เลือกตัวซ้ายสุดที่พบ: weevil_damaged›moldy›black›insect_damaged›broken›incomplete
  • ตัวอย่าง: ชิ้นเมล็ดแตกที่มีรูมอดมากกว่า 1 รู → insect_damaged
  • ตัวอย่าง: เมล็ดขึ้นราที่มีรอยด้วงกัดกิน → weevil_damaged เพราะรอยด้วงทำให้ทั้งล็อตไม่ผ่าน จึงต้องไม่ถูกบดบังด้วยคลาสอื่น
  • dried_cherry และ foreign_matter เป็นวัตถุคนละชนิดกับเมล็ด ไม่ต้องเทียบลำดับ
  • ถ้าไม่แน่ใจ ให้ใส่คลาสที่น่าจะเป็นที่สุด แล้วติด Tag ของภาพว่า unsure (Tag ไม่ใช่คลาส) ให้ผู้เชี่ยวชาญตรวจ · ถ้าลังเลระหว่างรอยมอดกับรอยด้วง ให้เลือก weevil_damaged ไว้ก่อน
ลำดับนี้เป็นข้อตกลงของทีม (มกษ. ไม่ได้กำหนด) ใช้เพื่อให้ทุกคนติดป้ายเหมือนกัน · weevil_damaged อยู่ลำดับแรกเพราะเป็นเกณฑ์ตีตกทั้งล็อต

4การถ่ายภาพ

  • ใช้กล่องไฟ แสงสม่ำเสมอ ไม่มีเงาแข็ง
  • ตั้งกล้องที่ความสูงคงที่ทุกภาพ
  • พื้นหลังด้าน (matte) สีตัดกับเมล็ด เช่น ฟ้าหรือขาว
  • กระจายเมล็ด ไม่ให้ซ้อนกัน
  • ถ่ายทั้งสองด้านเมื่อทำได้ (พลิกเมล็ด) แต่ต้องไม่นับเมล็ดเดียวกันซ้ำตอนคิด %
  • วางการ์ดสีหรือไม้บรรทัดสเกลไว้ในภาพ
  • ใช้ความละเอียดสูงพอให้เห็นรูมอดชัด เพื่อแยกรูเดียวกับหลายรู และแยกรอยมอดกับรอยด้วงได้

  3. อัปโหลดภาพ
  4. Annotate ด้วยเครื่องมือ Bounding Box
  5. Review / Approve ภาพที่ติดป้ายแล้ว
  6. แบ่ง Train / Valid / Test = 70 / 20 / 10
  7. Export ในรูปแบบ YOLOv8

เมื่อโมเดลพบ weevil_damaged: ระบบต้องไม่ออกผล "ผ่าน" แต่ให้แสดงสถานะ "รอผู้ตรวจยืนยัน" · ตารางที่ 3 ของ มกษ. กำหนดให้ตรวจร่องรอยด้วงโดยผู้ตรวจประเมินที่ผ่านการอบรม ผลจากโมเดลจึงใช้เป็นตัวคัดกรองเท่านั้น ไม่ใช่ผลตัดสิน

หมายเหตุ: มกษ. 5700 วัดข้อบกพร่องเป็น % โดยมวล คือคัดแยกจากตัวอย่าง ≥ 350 g แล้วชั่ง (ตารางที่ 3) แต่จากภาพนับได้เป็นจำนวนเมล็ดหรือพื้นที่ จึงต้องสอบเทียบกับการชั่งน้ำหนักจริงก่อนใช้ตัดสินผ่าน/ไม่ผ่าน
